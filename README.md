# Nuuli OI

Static homepage for `www.nuuli.com`, used as the main entry point for Nuuli's information olympiad learning resources.

## Entrypoints

- `https://l.nuuli.com` - 信奥教程
- `https://g.nuuli.com` - 信奥真题
- `https://play.nuuli.com` - Ryan 的花园（学生游戏作品）

Open `index.html` directly in a browser, or deploy the repository as a static site.
